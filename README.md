# Checkbox Ghost custom Theme 🚀

Кастомна тема для блогу **Checkbox**, побудована на базі Ghost Source Theme.

## 🛠 Технології

- **Ghost** (v5.0+)
- **Gulp** — збірка активів (CSS, JS)
- **BrowserSync** — живий перегляд змін при розробці
- **GitLab CI/CD** — автоматичний деплой через Ghost Admin API

---

## 💻 Локальна розробка

### 1. Попередня підготовка
- Node.js (рекомендовано v18+)
- Встановлений локально Ghost

### 2. Встановлення залежностей
```bash
# install dependencies
npm install
```

### 3. Режим розробки
Запустіть команду для відстеження змін у реальному часі:
```bash
# run development server
npm run dev
```
Команда скомпілює асети та запустить проксі-сервер BrowserSync на http://localhost:3000. Будь-які зміни в .hbs, .css або .js файлах автоматично оновлять сторінку.

### 4. Тестування (gscan)
Перед деплоєм перевірте тему на відповідність стандартам Ghost:
```bash
npm test
```

### 5. Можливість ручного завантаження теми
Gulp-завдання `zip` запаковує файли теми в архів `dist/checkbox-theme.zip`, який ви зможете завантажити у блог.
```bash
# create .zip file
npm run zip
```

## 🚀 Автоматизація та CI/CD

Цей репозиторій використовує GitLab CI/CD для автоматизації життєвого циклу теми.
Схема деплою:
Build: Створюється оптимізований .zip архів теми.
Deploy: Архів завантажується на сервер Ghost через Admin API та автоматично активується.
Notify: Бот надсилає звіт про статус деплою (успіх/помилка) у ваш Telegram-чат.

## 📂 Структура проєкту

/assets/css/ — вихідні стилі (основний файл screen.css).
/assets/js/ — клієнтські скрипти (мініфікуються в source.js).
/assets/built/ — згенеровані файли (не редагуйте їх вручну).
/partials/ — повторювані блоки шаблонів (хедер, футер, картки тощо).
default.hbs — головний каркас теми.

## ⚙️ Налаштування теми

Тема підтримує кастомні налаштування через package.json:
Постів на сторінку: 8
Custom Settings: Можливість задати main_site_url безпосередньо в адмін-панелі Ghost (розділ Design).
